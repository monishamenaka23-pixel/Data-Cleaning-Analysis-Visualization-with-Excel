# 🛒 E-Commerce Sales Analysis Using Microsoft Excel

## 📌 Project Overview

This mini project focuses on analyzing e-commerce sales data using Microsoft Excel. The project involves data cleaning, data validation, Excel formulas, PivotTables, descriptive statistics, and data visualization to transform raw data into meaningful business insights.

The analysis covers sales transactions, customer information, product details, and store data to understand sales performance and customer distribution.

## 🎯 Project Objectives

- Clean and organize raw e-commerce datasets.
- Identify missing values and check for duplicate records.
- Apply Excel formulas for calculations and data validation.
- Use VLOOKUP to retrieve information from multiple tables.
- Summarize data using PivotTables.
- Calculate descriptive statistics.
- Create charts and an interactive-style dashboard.
- Identify sales trends and patterns.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- Excel Formulas: `SUM`, `AVERAGE`, `IF`, `COUNTIF`, `VLOOKUP`
- PivotTables and PivotCharts
- Descriptive Statistics
- Data Visualization and Dashboard Design

## 📂 Dataset Description

The project contains four datasets:

| Dataset | Description | Records |
|---|---|---:|
| `Sales_Fact` | Sales transactions, quantities, prices, discounts, and payment types | 2,000 |
| `Customer Table` | Customer details, age, gender, location, and loyalty level | 500 |
| `Product_Dim` | Product names, categories, brands, cost, and stock | 100 |
| `Store_Dim` | Store names, regions, cities, and store types | 20 |

## 🔍 Project Workflow

### 1. Data Cleaning and Preparation
- Checked for missing values.
- Identified duplicate records.
- Reviewed data types and formatting.
- Standardized inconsistent values where appropriate.
- Documented data quality issues.

### 2. Data Analysis Using Excel Formulas
- Calculated sales amounts using quantity, unit price, and discount.
- Used logical formulas to validate calculated amounts.
- Applied VLOOKUP to retrieve related product information.
- Used summary formulas to analyze sales data.

### 3. PivotTable Analysis
Created summary tables to analyze:
- Total sales by payment type.
- Product count by category.
- Customer count by gender.
- Sales by store.
- Monthly sales trends.

### 4. Descriptive Statistics
Calculated the following statistics for sales amounts:

- Mean
- Median
- Mode
- Standard deviation
- Minimum
- Maximum
- Count

### 5. Data Visualization
Created charts to present key findings:

- 📊 Column Chart — Total Sales by Payment Type
- 📉 Bar Chart — Product Count by Category
- 🥧 Pie Chart — Customer Distribution by Gender
- 📈 Line Chart — Monthly Sales Trend

### 6. Dashboard
Designed an Excel dashboard to bring together key performance indicators and charts for a consolidated view of sales, products, and customer information.

## 📈 Key Findings

- **Sales Analysis:** Compared total sales across Credit Card, PayPal, and COD payment methods.
- **Product Analysis:** Analyzed 100 products across five categories: Beauty, Clothing, Electronics, Home, and Sports.
- **Customer Analysis:** Examined the distribution of 500 customers by gender.
- **Trend Analysis:** Prepared a monthly sales summary to observe changes in sales over time.
- **Data Quality:** Documented missing values and validation checks to support reliable analysis.
